# 実案件課題⑤：画像アップロードアプリ

## 1. 実装した機能

Next.js・TypeScript・Tailwind CSS・Supabase Storageを使用して、画像をアップロード・保存・表示・削除できるWebアプリを作成。

- 画像のドラッグ＆ドロップ
- ファイル選択による画像アップロード
- Supabase Storageへの画像保存
- アップロード済み画像の一覧表示
- ページ再読み込み後も保存済み画像を表示
- ドラッグ中のアップロードエリアの色変更
- アップロード済み画像の削除
- 削除後に画像一覧を自動更新

## 2. ファイルのバリデーション

アップロード前に、以下の条件をチェックするように実装。

- ファイルサイズ：5MB未満
- 対応形式：JPG・PNG・WebP
- 条件を満たさない場合はエラーメッセージを表示

## 3. 今回学んだこと

### ① Supabaseとは

データベースやファイル保存など、Webアプリに必要なバックエンド機能を提供するサービス。

今回はSupabase Storageを利用して、画像ファイルを保存した。

### ② Supabase Storageへの画像アップロード

`.upload()` を使用することで、選択した画像ファイルをSupabase Storageに保存できる。

また、`.getPublicUrl()` を使うことで、保存した画像を表示するためのURLを取得できる。

### ③ 環境変数（.env.local）

Supabaseの接続情報をソースコードに直接書かず、`.env.local` に分けて管理した。

GitHubに公開する際は、接続情報を含むファイルをアップロードしないことが重要。

### ④ useStateによる状態管理

Reactの `useState` を使用して、画面の状態を管理した。

今回使用した状態：

- `message`：成功・エラーメッセージ
- `selectedFile`：選択された画像ファイル
- `isDragging`：ドラッグ中かどうか
- `imageList`：アップロード済み画像の情報（ファイル名・URL）

状態が変更されると、Reactが画面を再描画する仕組みを学んだ。

### ⑤ useEffectによる初回読み込み

`useEffect` を使用して、ページが最初に表示されたタイミングで `fetchImages()` を実行するようにした。

これにより、ページを再読み込みしても、Supabaseに保存されている画像を取得して表示できる。

### ⑥ 非同期処理（async / await）

Supabaseへの画像アップロードや画像一覧の取得、画像削除は、処理が完了するまで時間がかかる。

`async / await` を使用することで、処理の完了を待ってから次の処理に進めることを学んだ。

### ⑦ Git・GitHubへの公開

Gitで変更内容を記録し、GitHubにソースコードを公開した。

また、GitHubのメールアドレス非公開設定によってPushが拒否されたため、GitHubのnoreplyメールアドレスを設定して対応した。

### ⑧ Supabase Storageからの画像削除

`.remove()` を使用することで、Supabase Storageに保存されている画像ファイルを削除できることを学んだ。

削除対象の画像を特定するために、画像のファイル名とURLをセットで管理するように変更した。

また、削除後に `fetchImages()` を実行することで、最新の画像一覧を取得して画面に反映できるようにした。

### ⑨ Supabaseのアクセス権限（ポリシー）

Supabase Storageでは、画像のアップロード・取得・削除などの操作ごとにアクセス権限を設定する必要があることを学んだ。

今回設定した権限：

- INSERT：画像のアップロード
- SELECT：画像一覧の取得
- DELETE：画像の削除

フロントエンド側に削除処理を書くだけでは不十分で、Supabase側でも削除を許可する設定が必要になることを理解した。

## 4. 今回意識したこと

- 画像をアップロードする前に、ファイル形式とサイズをチェックする
- 画像の保存先と、画面に表示するためのURLを区別する
- Supabaseの接続情報を環境変数で管理する
- ページを再読み込みしても画像が表示されるようにする
- 削除対象の画像をファイル名で特定する
- 画像を削除した後、最新の一覧を取得する
- GitHubに公開してはいけない情報を確認する

## 5. 今回の課題で理解したこと

今回の課題では、Webアプリの画面を作るだけでなく、外部サービスと接続してファイルを保存・取得・削除する流れを学んだ。

特に、以下の流れを理解することができた。

1. ユーザーが画像を選択する
2. ファイル形式とサイズをチェックする
3. Supabase Storageに画像をアップロードする
4. 保存された画像のURLを取得する
5. 画像一覧を取得して画面に表示する
6. ユーザーが削除ボタンを押す
7. Supabase Storageから対象画像を削除する
8. 最新の画像一覧を取得して画面を更新する
